# Lines starting with '#' and blank lines are ignored. Matching is case-insensitive.
#
# WHY THIS LIST LOOKS UNLIKE A "TOP 1000 PASSWORDS" FILE
#
# The minimum length is 12 characters, which already rejects almost everything on a
# conventional top-1k breach list — `password`, `123456`, `qwerty`, `letmein` and the
# rest are all shorter and never reach this check. A deny list bolted on top of a
# 12-character minimum only earns its keep against passwords that are LONG YET
# PREDICTABLE: repeated words, padded classics, and the "complex" patterns that
# composition rules taught a generation of users to produce.
#
# That is what this list is. It is a seed, not a corpus. Dropping in the full SecLists
# top-1k is a supported change — nothing here assumes the list is small — but doing so
# adds far less than it appears to, for the reason above.
#
# Adding an entry is cheap and permanent: it can only reject passwords, never accept one.
